# TruckersMP Server Analytics Hub

This is a first year university portfolio project

The application utilizes a **normalized relational database** to track active drivers, server capacity and server queues over time

Displays this data in a nicely formatted **Streamlit** application

* Uses the requests library to pull data from the offical Truckers MP API
* Puts data into a normalized relational database for effective storage
* Displays data in a Streamlit application window.
